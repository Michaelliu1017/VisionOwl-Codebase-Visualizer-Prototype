visionOwl · 桌面端前端布局方案

四个方案均严格遵循 skills/dark-glass-graph-ui 的视觉与交互契约， 直接复用其 dark-glass-graph-theme.css token； 图谱数据取自本仓库 test/ fixture 的真实模块结构（14 节点 / 26 边）。
四个方案的差异在面板架构，不是配色换皮。 点击任一节点可验证「选中 → 邻接高亮 → 无关变暗」全链路。
方案 A

IDE 三栏 + 底部 Agent 坞

模块树、图谱、详情三栏并置，Agent 收在底部通栏坞。信息全可见、零遮挡， 但画布被三面挤压。

最稳妥画布最小
方案 B

图谱优先 + 玻璃浮层

满幅画布，工具条/详情/Agent 全部为磨砂玻璃浮层。画布最大、最能体现这套 玻璃美学，但浮层会遮挡图谱，需要重叠降级方案。

画布最大有遮挡
方案 C

窄栏 + 右列堆叠

左侧只留 52px 图标栏，右列上下拆成详情 + Agent。详情与 Agent 同时常驻 且互不遮挡，画布比 A 更宽。宽屏下最平衡。

推荐右列偏挤
方案 D

Agent 主导工作台

Agent 对话升为左侧主面板，详情改为选中时右侧推入层。突出「让 agent 分析 模块」这一核心价值，代价是图谱不再是绝对主角。

Agent 优先图谱弱化
已实现的 skill 契约：单一权威状态、 邻接高亮为选中态投影（边不自持高亮）、单击选中/切换/取消、点击空白与 Esc 清空、 相关节点保持正常亮度而仅无关节点降亮、边界锚点连线（非中心到中心）、 每条边双路径（宽透明命中路径 + 可见路径）、边层位于节点之下、 节点背景完全不透明防止边线穿透、prefers-reduced-motion 降级。
